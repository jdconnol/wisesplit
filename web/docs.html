WiseSplit documentation

WiseSplit is a self-hosted Splitwise alternative (a fork of SplitPro) plus an MCP connector that lets an AI agent drive it.

Overview

Two pieces:

  • WiseSplit server — the web/PWA app and API (Next.js + Postgres). Installs on Android & iOS as a PWA.
  • MCP connector — a small server that exposes WiseSplit to Claude (or any MCP client) via a Personal Access Token.
Single-operator by design: one token identifies one user, and the agent acts as you. Your friends use the app normally.

Prerequisites

  • Node.js 22, pnpm 10
  • PostgreSQL (with pg_cron for recurring expenses — the prod Docker image includes it)
  • An SMTP server for login + email notifications (any provider, or a local catcher in dev)

Run the server

cd app
cp .env.example .env        # set DATABASE_URL, NEXTAUTH_SECRET, EMAIL_SERVER_*, CURRENCY_RATE_PROVIDER=frankfurter
pnpm install
pnpm prisma migrate deploy
pnpm db:seed                # optional demo data
pnpm dev                    # http://localhost:3000
After seeding demo data, resync the id sequences once: SELECT setval(pg_get_serial_sequence('"User"','id'), (SELECT MAX(id) FROM "User")); (and the same for "Group").

Install on Android

Two options:

  1. PWA (recommended, works today): open your WiseSplit URL in Chrome → menu → Install app / Add to Home screen. Full-screen app with push notifications, no sideloading needed.
  2. Sideloadable / Play-Store APK: a TWA wraps your hosted PWA, so deploy WiseSplit first, then build a signed APK in one command using the included project: 
    DOMAIN=your.wisesplit.domain bash android/build-apk.sh
    Sideload the resulting app-release-signed.apk (Settings → Apps → Install unknown apps → allow your browser/Files), or upload it to the Play Store.
A TWA points at your live HTTPS instance — there is no offline APK because WiseSplit needs its backend. The PWA path needs nothing but a browser.

Install on iOS

iOS installs WiseSplit as a Progressive Web App — full-screen, home-screen icon, push notifications:

  1. Open your WiseSplit URL in Safari.
  2. Tap the Share button → Add to Home Screen → Add.
  3. Launch it from your home screen like any app.
A sideloadable signed .ipa requires an Apple Developer account and code-signing (via Xcode / AltStore). Apple does not allow distributing unsigned iOS binaries, so the PWA is the supported install path. The full-screen PWA is functionally equivalent for day-to-day use.

Create an access token

The agent authenticates with a Personal Access Token (only its hash is stored):

cd app
pnpm tsx --env-file=.env scripts/create-api-token.ts \
  --email you@example.com --scope read_write --name "MCP"

Use --scope read for a read-only token (it’s rejected on any write). Tokens are rate-limited to 60 requests/minute.

Connect the MCP connector

cd mcp
npm install && npm run build

Add to your MCP client config (e.g. Claude Code .mcp.json):

{
  "mcpServers": {
    "wisesplit": {
      "command": "node",
      "args": ["/absolute/path/to/mcp/dist/index.js"],
      "env": {
        "SPLITPRO_URL": "http://localhost:3000",
        "SPLITPRO_TOKEN": "spat_your_token_here"
      }
    }
  }
}

Then talk to your agent: “add €40 dinner split with Nathen and Maverick”, “what do I owe?”, “settle up €20 with Emma”.

Troubleshooting

  • 401 from the agent: the token is wrong/expired — re-issue one.
  • 403 “read-only”: you used a read-scope token on a write — issue a read_write token.
  • group.create fails with a unique id error: demo seed left sequences stale — run the setval commands above.
  • Recurring expenses don’t fire: your Postgres needs pg_cron (use the prod Docker image).
