How it works

WiseSplit is the data + ledger; your AI agent is the interface. The web/mobile app is always there as a visual fallback.

1

Run the app

Self-host the WiseSplit server (a SplitPro fork). It’s a normal web app that installs on Android & iOS as a PWA, with the full split/balance/settle ledger.

2

Connect the agent

The MCP server exposes WiseSplit to Claude (or any MCP client) using a Personal Access Token. Reads are open; writes are previewed and idempotent.

3

Just talk

Add expenses, settle up, check balances, search history — all in plain language. Friends use the app; you can use the agent.

Everything you actually use

The whole Splitwise core, plus an agent that replaces the premium tier.

⚖️

Every split type

Equal, exact, percentage, shares, adjustment — computed precisely with no floating-point cent drift (BigInt math).

👥

Groups & balances

Trips, households, couples. Live who-owes-whom with debt simplification, settle-up, and an activity feed.

🤖

Agent-native

8 MCP tools: add, settle, search, group management. Preview-before-write so the agent can’t mis-post.

🔁

Recurring & multi-currency

Rent and subscriptions auto-post; live FX conversion across currencies, no API key required.

🔔

Push & email alerts

Friends get notified of new expenses and settle-ups by push notification and email.

🔒

Yours, private

Self-hosted. Scoped, rate-limited access tokens. No ads, no subscriptions, your data on your server.
